Why this customized ISO?

On some OEM laptops, the Windows product key is embedded in the BIOS/UEFI firmware. During Windows Setup, this can cause the Home edition to be automatically selected without showing the usual Home / Pro edition selection screen.

This customized installation media contains Windows 10 Pro only and is intended for compatible systems where you specifically need to install the Pro edition.

The installation media does not include the other Windows editions.
